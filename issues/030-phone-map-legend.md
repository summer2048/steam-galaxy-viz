## 背景

028 只修了 Studio 的三个页面。做 022 时用 375 px iframe 看星图本身，发现星图在手机上还有几处排版问题。

## 证据

375 px、中英文（scratchpad 的 phone_panel 截图）：

- 星图左下的图例（“线越亮 = 组合成功率越高 / 线越粗 = 同时出现越多”）挤在约 50 px 宽的一列里，中文每行一个字，英文每行一个词。
- 右上的语言按钮（中文 / EN）在窄屏被拉成约 320 px 高的竖条，压在筛选面板上。
- 选中标签后，侧栏在 iframe 截图里看不到（DOM 里 `#tagFirst` 和侧栏都在：侧栏 top 684 px、宽 324 px，022 的首屏块宽 276 px），需要在真机或 DevTools 设备模式确认是截图时机问题还是确实不可见。

## 建议

1. 窄屏把图例改成一行两项（短线 + 短句），宽度跟随容器。
2. 语言按钮在窄屏固定为圆角小按钮，不随父容器拉伸。
3. 用 DevTools 设备模式确认选中标签后侧栏的位置和可见性。

## 验收标准

- 375 px 中英文：图例每行至少一个完整短句；语言按钮高度 ≤ 40 px；选中标签后侧栏可见，`#tagFirst` 的观察句在侧栏首屏。
