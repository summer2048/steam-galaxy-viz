| 切换角色会清空分享链接带入的游戏 | **Node 状态逻辑实测**。关注清单为空时，玩家链接带入 1 款游戏，切到开发者再切回玩家，已玩游戏变为 0 款，推荐随之消失。`scripts/studio.js:102、126–135` | 保留链接指定的游戏和标签。只在首次进入或上次选择来自关注清单时自动填入。 |
| 按一次 Esc 会同时关闭 Studio 并取消星图选区 | **代码判断**。从标签侧栏进入 Studio 后，在按钮上按 Esc 会先关闭 Studio；同一按键随后传到星图，又清除原先选中的游戏或标签。键盘用户返回后需要重新定位。`scripts/studio.js:85、138`，`scripts/template.html:2580` | Studio 处理 Esc 后停止事件冒泡。验证按一次返回原选区，再按一次才取消选择。 |
| 对标卡会把第二名写成“超过 100%” | **本地数据实测，显示按代码核对**。2020 年的 `Indie` 赛道有 5,388 款游戏，《Fall Guys》评价数排第二，低于它的有 5,386 款。对标卡把这个比例四舍五入为 100%，让开发者误以为它超过了第一名。`scripts/studio.js:168–169` | 直接写“同年同赛道第 2 名，共 5,388 款”，并列时注明并列。 |
| 手机上从侧栏进入 Studio，语言按钮仍浮在内容区 | **代码判断，未经真机验证**。星图侧栏打开时，语言按钮距底部约 `62vh`。进入 Studio 后仍沿用这个位置，且层级高于全屏内容，滚动时可能挡住卡片或操作按钮。`scripts/template.html:602`，`scripts/studio.css:3–5` | 在手机端把语言按钮放入 Studio 顶栏，或为 Studio 单独设置位置。 |
