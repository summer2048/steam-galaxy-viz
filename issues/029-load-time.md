## 背景
页面 40 MB（内嵌 83,353 款游戏的逐款表），担心普通笔记本加载和首次打开 Studio 太慢。

## 证据
无头 Chrome，不用虚拟时间（虚拟时间会让 `performance.now` 失真），各跑 3 次取中位数。本机 24 核。

| 步骤 | 中位数 |
|---|---|
| 打开页面到 body 解析完 | 440 ms |
| Studio 首次打开：解析逐款表 JSON | 8 ms |
| 建立索引（`GameDB.open`） | 21 ms |
| 第一次推荐（建候选池和百分位） | 88 ms |
| 再推荐一次（有缓存） | 44 ms |
| 赛道的搭配标签分析 | 6 ms |

JS 堆 109 MB。

## 建议
不需要改。按 5 倍慢的笔记本估算：加载约 2 秒，推荐约 0.5 秒，都可以接受。如果以后放到网上，40 MB 的下载才是瓶颈，届时再考虑把逐款表拆成单独文件并压缩。
