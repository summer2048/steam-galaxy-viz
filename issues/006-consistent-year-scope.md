## 背景
`top`、`devs`、`covers`、`games` 取自全部年份，KPI 取自 2018–2024。`base.year` 含无标签游戏，`base.hit` 只算有标签的。来自 001 的建议 5 和 C 节。

## 证据
见 001 的 C 节。全部游戏视图的 Top 1 是一款 2012 年的游戏。

## 建议
001 给了两个方案：限定到 2018–2024，或者明确标注"全部年份"。目前做了标注。要不要真的限定，需要决定：球面代表作如果只取 2018–2024，很多标签会失去最有辨识度的封面，我的看法是封面保留全部年份、榜单限定年份，但这需要重跑管线和重新下载封面。

## 验收标准
- [x] 取自全部年份的地方都有标注：封面拼图计数、评价最多的游戏、开发商榜、About、README。
- [x] 成功率的年份基线统一为有标签游戏（见 002）。
- [x] Finding 1 注明统计的是 Steam 全部游戏（含无标签的）。
- [x] 决定榜单是否限定到 2018–2024；如果限定，改 `export.py` 的 `top_games` 和 `devs` 并重跑管线。
